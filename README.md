# 案件管理ダッシュボード

このフォルダがダッシュボードの正本です。公開用ファイルは常に `index.html` で、修正のたびに `dashboard_v60.html` のような複製を作る必要はありません。公開履歴は旧履歴を引き継がない新規リポジトリ `ichilolule/illustration-dashboard` から始めています。移行前の履歴は非公開の旧リポジトリに保管しています。

公開URLは `https://ichilolule.github.io/illustration-dashboard/` です。旧 `/dashboard/` のPages公開は停止済みです。Chromeのブックマークやインストール済みWebアプリは新URLへ設定し直してください。同じChromeプロファイルでは旧URLと新URLのブラウザ保存データを共有します。

## 普段の流れ

1. ChatGPTデスクトップでこのフォルダのプロジェクトを開く。
2. 修正内容を伝え、実装・表示確認・テストまで依頼する。
3. HTMLプレビューと変更差分を確認する。
4. 問題がなければ「GitHubへ公開して」と伝える。

Codexが `index.html` と必要な関連ファイルを直接更新し、公開依頼時にコミットとpushを行います。

## 確認コマンド

Googleカレンダー連携のロジックテスト：

```sh
node --test tests/case-state-core.test.cjs tests/calendar-sync.test.cjs
```

PlaywrightとChromiumが利用できる場合の画面テスト：

```sh
node tests/calendar-ui-smoke.cjs
```

Google連携の初回設定と実機確認は `CALENDAR_SYNC.md` を参照してください。

Chromeでは、設定タブの「バックアップ」から `dashboard_sync.json` の保存先を複数追加できます。フォルダを選ぶ事前設定は不要です。各保存先で同じファイル名を選び、案件や設定の変更時に自動上書きします。従来の1件の保存先は自動で引き継ぎます。

`dashboard_sync.json` には案件・アーカイブ・設定・休日・Google連携設定を含みます。旧版の発行者プロフィールと請求書採番情報は新しいバックアップに含めません。旧形式の完全バックアップは引き続き読み込めますが、その中の発行者プロフィールと採番情報は復元しません。案件内の依頼者名や連絡先などはバックアップに含まれます。

保存先はそれぞれ名前を付けて管理でき、保存・変更・解除・読み込みを個別に行えます。外部更新を検知した保存先だけ自動保存を止めます。「解除」は登録を外すだけで、ファイルは削除しません。Google DriveやiCloud Driveへの同期完了は各サービス側で確認してください。

以前の `dashboard_cases.json` の書き出し・読み込みは終了しました。既存のファイルは削除されません。個別案件のJSON貼り付けによる追加は引き続き利用できます。
